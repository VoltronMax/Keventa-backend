# Roles y permisos

Este documento tiene como objetivo describir los diferentes roles disponibles en Keventa, así como las acciones que cada uno puede realizar dentro del sistema.
## Roles

### Admin:

Es la persona encargada de administrar el sistema y gestionar todos los procesos relacionados con la Boutique.

- Tiene acceso completo a todas las funcionalidades del sistema.
- Puede crear, modificar y eliminar la información registrada.
- Es el responsable de administrar los usuarios y supervisar el funcionamiento general del sistema.
### Employee (Empleado):

Es el personal autorizado para realizar las actividades diarias relacionadas con las ventas y la consulta de información necesaria para atender a los clientes.

#### Puede:

- Registrar ventas.
- Consultar el historial de ventas.
- Buscar productos.
- Consultar la información y disponibilidad de los productos.

### No puede:

- Crear, modificar o eliminar productos.
- Administrar usuarios del sistema.
- Cancelar ventas ni registrar devoluciones.
- Modificar manualmente el inventario.
